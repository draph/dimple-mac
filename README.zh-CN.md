# Dimple — Folder icons for Mac

[English](README.md) | 简体中文

> 开发中。本文是首版使用说明草稿，描述目标产品行为，不代表当前实现进度。目前尚无公开安装包；下载信息、支持系统和签名状态将在公开前按实际发布包核实。

当前开发版本支持选择文件夹、查看和移除目标，以及20 个离线内置图标（开发、工具、箭头、媒体各 5 个）、中英文搜索与分类筛选。目标按目录身份校验与去重，并显示逐项错误和符号链接详情。已接通内置徽标应用与确认后恢复默认；覆盖已有自定义图标和链接目标需要确认，覆盖不保留备份。结果确定后可直接开始新编辑，无效输入或取消选择保留原上下文；全部成功约一秒后释放目标，面板保持显示。WebView 重载会恢复当前操作，不重放写入。已支持 PNG／静态 SVG 安全导入、仅使用 Alpha 及透明留白裁剪；文字徽标支持单行 1–4 个用户可见字符、中文输入法组词后自动预览、系统字体回退与缺字提示，文字和图标素材互斥；批量操作支持部分失败、停止剩余项、按原快照重试失败项和继续未执行项；已接入窗口隐藏规则与面板内快捷键设置，多屏与拔屏行为已通过用户手动验收。原生写入采用系统文件协调与身份复核，无法阻止绕过协调的程序替换路径。

一款 macOS 菜单栏工具，为文件夹添加具有原生凹陷质感的自定义图标。选中文件夹、选择徽标、应用，在同一个面板完成。

Dimple 是独立维护的图形界面项目，以 [lgarron/folderify](https://github.com/lgarron/folderify) 为参考，并非其官方桌面版本。使用 Tauri v2、Rust、React、TypeScript、Vite 和 Tailwind。

## 功能

- 为单个文件夹或最多 100 个文件夹批量应用图标。
- 选择内置图标、导入透明 PNG 或静态 SVG，或输入单行 1–4 个可见字符作为徽标。
- 实时预览，可按需调整缩放、位置和文件夹颜色。
- 通过菜单栏、全局快捷键或 Finder 右键服务打开面板；支持向面板或菜单栏拖入文件夹或徽标文件。
- 确认后恢复系统默认文件夹图标。
- 离线使用，无账号、遥测、上传或运行时网络依赖。
- 支持简体中文、英文、键盘操作及 VoiceOver。

## 安装

发布目标是面向 Apple Silicon 和 Intel Mac 的 Universal 应用及 DMG。构建要求 macOS 13.3 或更新版本，以覆盖 Tailwind CSS v4 所需的 Safari 16.4 WebKit 能力及原生 HTML 确认框。此配置下限不代表已经验证的支持范围：Intel、旧系统和特殊存储环境仍未验证。已测硬件和存储、下载位置、SHA-256 及签名／公证状态将在公开前记录。

安装发布版时，打开 DMG，将 **Dimple** 拖入**应用程序**，然后启动。安装包自带运行所需资源，无需安装 Python、ImageMagick、Homebrew 或开发工具。

遵循对应版本附带的签名和安装说明。未签名或未公证的构建须标为预发布；安装流程不要求关闭 macOS 安全保护。

## 授权

首次使用 Finder 选中项读取功能时，应用会请求 Finder 自动化权限。拒绝后仍可手动选择文件夹或将其拖入面板。需要修改权限时，在**系统设置 → 隐私与安全性 → 自动化**中查看 Dimple 对 Finder 的访问；系统名称可能因 macOS 版本而异。

应用不自动提权。目标须为可写文件夹；系统保护目录和应用包会被拒绝。

## 基本使用

1. 在 Finder 中选中文件夹，点击菜单栏图标或按默认快捷键 **Option + F**。也可向面板拖入文件夹、使用文件夹选择器或调用 Finder 服务。
2. 选择内置徽标、导入 PNG／SVG，或输入文字。预览在顶部目标卡片内更新，批量目标共用新效果，无需展开调整区。
3. 点击**应用**。如果会覆盖已有自定义图标，核对受影响目标后确认。

Finder 不在前台时，请手动选择目标。手动选择的目标在重新打开面板时保留；点击**选择文件夹**旁的下拉箭头，选择**使用 Finder 中选中的文件夹**可主动替换。菜单支持键盘操作，点击外部或按 **Esc** 关闭。目标摘要及可展开列表显示将处理的文件夹，应用前可逐项移除；多个目标时，展开列表可选择**全部移除**，保留当前徽标和调整参数。

仅在隐藏面板被唤起、没有手动目标或未完成操作时自动读取 Finder。自动读取失败会清除旧自动目标，不能使用旧选择继续应用。拖拽或选择中无效的项目逐项提示；全部无效、超过 100 个有效目录、目录与徽标混合或多个徽标时保留原目标和素材。

应用启动时直接显示主窗口，失焦或操作成功后保持显示。全部成功后，在成功提示结束时（约一秒）释放已处理目标。点击窗口 **X**，或使用原生隐藏菜单／**Cmd+H** 隐藏窗口；隐藏保留运行期编辑内容，不等于退出。选择器、确认框、输入处理和未决写入期间不能隐藏。**Esc** 不隐藏窗口，仍可取消当前确认框或结束快捷键录入；输入法组词和系统选择器内交由 macOS 处理。

从菜单栏或面板右上角的设置图标进入独立**设置**页面；准备、确认、执行及等待未决结果期间暂缓进入，任务结束后可重新打开。点击**返回**回到主界面；编辑状态保持。图标徽标和文字徽标通过标签切换，切换本身不会替换当前徽标，选择图标或输入文字后才替换。设置页底部提供**退出**按钮，菜单栏退出入口仍可使用。可启用或关闭全局快捷键；点击录入框（或按回车）、按含 **⌥ Option**、**⌃ Control** 或 **⌘ Command** 的组合键，按 **Esc** 结束录入，再点击**保存**。默认值为 **⌥F**。录入期间按键用于捕获，不执行应用的原生菜单动作。与其他 Carbon 独占注册冲突或保存失败会显示错误及当前实际生效组合键；回滚失败可能需要先退出并重新打开应用再修改，菜单栏仍可用。 macOS 仍允许旧式非独占注册及其他快捷键机制共享组合，无法检测所有系统保留快捷键。

设置页的“关于”信息区紧凑显示 Dimple 和当前安装包版本，并注明更新功能暂不可用。

在**设置 → 外观**中选择**跟随系统**、**深色**或**浅色**。默认为跟随系统，应用运行时响应 macOS 外观变化。切换立即生效并自动保存到应用 WebView 的本地存储，无需点击快捷键的保存。深色使用中性黑灰底色和蓝色强调；外观不改变文件夹预览或已应用的图标。选择**跟随系统**可重置此偏好。

在**设置 → 语言**中选择**跟随系统**、**简体中文**或**English**。默认为跟随系统，应用在启动或重新选择该项时解析 macOS 为本应用提供的首选支持语言；没有匹配时使用英文。手动选择会立即应用到面板、设置和原生菜单并保存，直到重新选择跟随系统。应用不实时监听 macOS 语言变化；系统语言改变后需重启或重新选择跟随系统。语言只影响呈现，不改变文件夹名称、路径或用户输入的徽标文字。

快捷键保存到 `~/Library/Application Support/dev.efun.folderify-desktop/shortcut.json`，语言偏好单独保存到 `language.json`。文件缺失时使用默认值；不可读或损坏时提示并使用默认值，主动保存前保留原文件。启动注册冲突不改写已保存的快捷键偏好。面板从菜单栏图标附近或鼠标所在屏幕打开，按可用区域夹取，内容过高时内部滚动。应用不透明背景使用所选外观，系统原生对话框仍跟随 macOS；多屏／拔屏行为已由用户手动验收。

### 徽标与调整

内置图标可按名称、分类或中英文关键词搜索。导入时一次选择一张 PNG 或静态 SVG，文件不超过 10 MiB；栅格化输入单边不超过 4096 像素，总像素不超过 1600 万。SVG 支持路径、基本形状、分组、变换、渐变、内部引用、裁剪和静态遮罩。脚本、外部资源、DTD／实体、HTML、动画、文字、嵌入图像、滤镜、虚线描边、样式表及未知特性会整份拒绝。SVG 必须为 UTF-8、使用标准 SVG 命名空间，并具有有效尺寸或 viewBox。内联样式仅接受受限的简单声明；函数形式的画笔值请使用表现属性。复杂度限制包含 20,000 个元素／展开节点、深度 64、200,000 个路径命令；载入超过 10 秒会终止，不静默忽略不支持的内容。

导入失败会保留上次有效徽标和目标上下文，但应用按钮保持禁用，直到恢复有效徽标或重新选择；WebView 重载也会保留此状态。

徽标使用图像透明度，而非图像颜色。透明留白不参与缩放定位；完全不透明的 PNG 会形成实心矩形。文字支持单行 1–4 个中文、英文或数字等可见字符，纯空白和无法显示的字形会被拒绝。

展开**调整**可修改缩放、水平／垂直位置及文件夹颜色。预设包括原生蓝、红、橙、黄、绿、紫、灰，也可使用自定义颜色。**重置参数**保留目标和徽标，仅恢复调整参数，不修改磁盘上的图标。缩放范围为 0.25–2（步长 0.01）；双轴偏移均为 −100–100（步长 1，1024 像素画布上每单位 2 像素）。颜色只提供色相和饱和度，保留底图亮度和 Alpha，黑、白和灰输入会得到相近的灰色文件夹。参数保存在运行期内存，WebView 重载后恢复，退出应用即清除。主题色和刻印参数仍为候选值，最终视觉校准留在 T14。

### 恢复默认与处理部分结果

在次要操作菜单中选择**恢复默认图标**并确认目标。该操作清除自定义图标，让 Finder 使用系统默认图标，**不会找回之前的自定义图标**。覆盖和恢复均不提供备份或撤销。

批量结果区分成功、失败和未执行目标。**重试失败项**只重试允许安全重试的失败目标；**继续剩余项**沿用原操作和调整参数，处理尚未开始的目标，跳过成功项。**停止剩余项**会等待当前写入结束，再停止后续目标。

系统写入耗时较长时，请等待结果；超时不代表写入已取消，结果未确定时不能重试。写入成功后，Finder 可能需要一些时间刷新显示。结果确定后可直接开始新编辑；接受有效新编辑会清除旧的重试／继续上下文。

## 限制与隐私

- 仅面向 macOS。发布时列出已测系统版本、架构和存储组合，不承诺未经验证的组合可用。
- 每次最多处理 100 个文件夹，不递归处理其内容。符号链接会解析到实际文件夹，并要求确认。
- 外接盘、网络盘和云同步目录取决于权限及文件系统行为，不保证图标跨设备同步。
- 固定使用 Big Sur 浅色原生蓝作为文件夹底图基准，不随系统版本或界面深浅色切换。文件夹着色与应用界面深浅色相互独立。
- 写入方案采用 macOS 文件协调与身份复核；绕过协调的程序仍可能在最终检查后替换路径，不能将其视为约束所有进程的强制锁。
- 预览和调参不写入目标；应用和恢复只修改文件夹图标元数据，不修改文件夹正文内容。
- 退出后不保存目标路径、导入素材或编辑草稿；快捷键、外观和语言偏好会保存。日志不得包含完整私人路径、素材内容或凭据。
- 不提供独立 PNG／ICNS 导出、编辑历史、旧图标备份／撤销、预设管理、自动更新或插件市场。

## 语言

应用默认跟随 macOS 为其解析的首选支持语言，在简体中文和英文中选择，无匹配时回退英文；也可在**设置 → 语言**中选择**跟随系统**、**简体中文**或 **English**。手动选择会立即应用到面板、设置和原生菜单并保存，直到重新选择跟随系统。跟随系统在启动或重新选择时解析，不实时监听 macOS 语言变化；系统语言改变后需重启或重新选择跟随系统。语言只影响呈现，不改变文件夹名称、路径或用户输入的徽标文字。

## 从源码构建

使用 Node.js 24、npm 12、`rust-toolchain.toml` 固定的 Rust 工具链，以及带 macOS SDK 的 Xcode 或 Command Line Tools。尚未安装 Rust 时，先通过 [rustup.rs](https://rustup.rs/) 安装。依赖由 npm 和 Cargo lockfile 固定。

```sh
git clone https://github.com/draph/dimple-mac.git
cd dimple-mac
source "$HOME/.cargo/env"
npm ci
npm run tauri dev
```

执行检查并构建原生可执行文件：

```sh
npm run typecheck
npm test
npm run build
npm run check:rust
npm run tauri build -- --no-bundle
```

构建 Universal 应用和 DMG：

```sh
rustup target add aarch64-apple-darwin x86_64-apple-darwin
npm run tauri build -- --target universal-apple-darwin
```

构建产物位于 `src-tauri/target/` 下。可执行文件和进程名均为 `Dimple`，与应用名一致。本地应用包使用完整的 ad-hoc 签名，暂不启用 hardened runtime；这不等于 Developer ID 签名或公证。可用 `codesign --verify --deep --strict --verbose=2 path/to/Dimple.app` 验证应用包。发行签名和运行兼容性仍须单独验证。`check:rust` 执行 fmt、Clippy（警告视为错误）和单元测试。文件夹写入测试必须使用隔离临时目录。

打包后的应用应从 Finder、聚焦或 `open path/to/Dimple.app` 启动。直接运行 `Contents/MacOS` 内的可执行文件可能继承终端宿主的 macOS 进程归属。macOS 26 中，与已禁用宿主的残留菜单栏关联可能导致 Dimple 开关已开启但图标仍隐藏。不要将重置控制中心或修改其私有配置作为常规安装步骤。应用标识继续保留 `dev.efun.folderify-desktop`，以沿用改名前的设置和系统权限。

## 卸载

如果希望恢复系统默认图标，请先在应用中执行恢复。从菜单栏退出 Dimple，再将其从**应用程序**移至废纸篓。删除应用不会清除已经应用的文件夹图标，也不会恢复被覆盖的自定义图标。源码目录和开发工具链独立管理。

可选删除 `~/Library/Application Support/dev.efun.folderify-desktop/shortcut.json` 和 `language.json`，以重置保存的快捷键和语言。
